Which protocol without a token is worth farming next?

Every protocol in the snapshot that records no token — never “has none”, the record is not proof — ranked by what its launch would be worth if its record stayed as it is. The value is this board’s own claim, built from the market’s own verdict on protocols that already trade.

How the implied value is built

implied value = TVL × category multiple × growth × maturity × breadth × launch-likelihood

  1. Category multiple — the median market-cap-per-TVL of the trading protocols in the same category, from this snapshot alone (global median when a category has fewer than 3 traders). No hardcoded list of names.
  2. Growth — the protocol’s 7-day TVL change, clamped to −40%…+80%, moving the value by at most ±48%.
  3. Maturity — how long it has run with no token: +5% per year listed, capped at +25%. An old protocol still waiting is more “overdue” than a new one.
  4. Breadth — +4% per extra chain, capped at +16%.
  5. Launch-likelihood — the haircut: a CEX, a bridge or a wrapped/staked product is priced as a long shot (×0.01–0.02), not a launch candidate, whatever its TVL.

Each row’s detail view shows its own numbers, so you can check the arithmetic. Trading protocols are not on this board — they appear only as comparables, the market evidence behind each multiple.
